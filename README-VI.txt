LISTENTOTWENTYTHREE — COURSERA RESPONSIVE SITE

Files:
- index.html: page structure, title, headings, 3 track cards, images and links
- style.css: mobile-first design plus the two required media queries
- images/ig-model.svg and images/the-highest.svg: original decorative poster graphics

Coursera rubric check in style.css:
1) @media (min-width: 772px): div width 45vw; display inline-block; img max-height 30vh
2) @media (min-width: 998px): div width 30vw

Image note:
- Queen St uses the direct cover-art image URL surfaced by Shazam/Apple Music.
- IG MODEL and The Highest use original decorative poster graphics rather than pretending that unverified artwork is official. Each card links to the named track on a music platform.

To run in Coursera Lab:
1. Open /home/coder/project in VS Code.
2. Put index.html, style.css, and the images folder in that project folder.
3. Open index.html in Preview / your local server.
4. Resize the viewport to below 772px, 772–997px, and 998px or wider.
5. Publish through GitHub Pages or the hosting feature supplied by the lab to get a public submission URL. The ZIP itself is not a public website URL.
